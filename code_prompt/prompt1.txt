3. **MTTR Calculation (Mean Time To Resolve):**
   - Calculate resolution times (MTTR) separately for **P1** (Target SLA = 4 Hours) and **P2** (Target SLA = 8 Hours).
4. **Report Injection:**

3. **MTTR Calculation:**
   - Calculate MTTR separately for P1 (4h target) and P2 (8h target) for each domain.
4. **Report Injection:**
   - Inject calculated metrics into the 3 sheets of the report template, mapping each sub-domain to its corresponding row:
